## Ziel

MemFuse als Model Context Protocol (MCP) Server deklarieren, sodass externe
LLM-Agenten (Claude, GPT, lokale Modelle) MemFuse automatisch als
Context-Provider entdecken und dessen Such-API nutzen können.

---

## Strategischer Kontext

MCP ist der de-facto Standard für Tool-Integration in LLM-Agenten-Systeme.
Ohne MCP-Support ist MemFuse ein isoliertes Silo — Agenten müssen
manuell gegen die Python-API kodiert werden. Mit MCP wird MemFuse
ein universeller, auto-discoverbarer Wissensspeicher.

Dies ist besonders kritisch für die "Invisible Engine"-Strategie:
Wenn MemFuse als MCP-Server in Atlas (Tauri) läuft, können beliebige
Agenten ohne API-Kenntnis darauf zugreifen.

### FR-7.3-002: Python MCP Server

```python
from memfuse import MemFuse
from memfuse.mcp import MCPServer

db = MemFuse(path="./brain")
server = MCPServer(db)
server.run(transport="stdio")  # oder "sse"
```

### FR-7.3-003: Auto-Embedding bei Insert

Wenn `memfuse-embed` (WP nach GS-06) verfügbar ist, wird `text` automatisch
embedded. Ohne Embedding-Provider muss der Client Vektoren mitliefern.

## Invarianten

1. **MCP Spec Compliance**: Manifest valide gegen MCP JSON Schema
2. **Kein Network-Access bei Air-Gap**: `transport="stdio"` erfordert keine Sockets
3. **Thread-safe**: MCP-Server nutzt shared `Arc<MemFuse>`
