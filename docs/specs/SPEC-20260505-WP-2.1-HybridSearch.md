## Ziel

Kombination von Vektor-Suche (HNSW) + Keyword-Suche (BM25) via Reciprocal Rank Fusion.  
Marktstandard für RAG-Systeme. Kein externer Search-Engine Dependency (kein Tantivy).

---

## Invarianten

1. **Keine neue Abhängigkeit > 500 LoC transitiv** — keine Tantivy, Lucene, etc.
2. BM25 muss auf dem **gleichen LSM-Store** wie Vektordaten arbeiten (kein separater Index)
3. `hybrid_search(text="", vector=q, k=5)` → verhält sich identisch zu `search(vector=q, k=5)`
4. `hybrid_search(text="foo bar", vector=zero_vec, k=5)` → BM25-dominiert, Vektor wird ignoriert

## RRF-Formel

```
score(doc) = Σ_{r ∈ result_sets} 1 / (k + rank_r(doc))
k = 60  (Standard-Wert, konfigurierbar)
```
