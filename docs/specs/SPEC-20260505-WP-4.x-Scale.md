# SPEC-20260505-WP-4.1 — Memory-Mapped I/O (mmap)

> **Priority:** 🟡 MITTEL  
> **Dependency:** WP-1.1 + WP-3.2 DONE  
> **DONE-Definition:** 2 Tests bestehen 3×. Read-Throughput >= 2× vs. explicit read().  
> **Assigned:** Jules Account 02 (store)
> **Status:** ✅ DONE

---

## Ziel

SSTable-Reads über OS-Page-Cache statt explizite `read()` Syscalls.  
Eliminiert User-Space-Kopien und nutzt OS-Prefetching.

---

## Invarianten

1. **Boundary-Check** vor jedem Offset-Zugriff (kein OOB bei korrupten Dateien)
2. **Drop ordentlich**: `Mmap` wird bei `SstableReader::drop()` unmapped
3. **Encrypted SSTables**: `mmap` + decrypt-on-read (decrypt per Block, nicht die ganze Datei)
4. `#[allow(unsafe_code)]` mit **Kommentar** der Sicherheitsbegründung

---

| # | Test | Erwartung |
|---|---|---|
| AC-1 | `test_mmap_read_correct_values` | 100 Einträge schreiben, via mmap lesen → alle korrekt |
| AC-2 | `test_mmap_concurrent_readers` | 16 tokio-Tasks lesen gleichzeitig → kein Panic, alle Werte korrekt |

**Dependency:** `memmap2 = "0.9"` (sicherer mmap-Wrapper, zero unsafe exposure)
