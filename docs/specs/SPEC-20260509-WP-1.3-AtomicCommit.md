# SPEC-20260509-WP-1.3-AtomicCommit

> **Status:** ✅ DONE

## 🎯 1. Das Ziel (Context & "Why")
Die Behebung der S2-Schwachstelle "Atomic Multi-Index Commit". Aktuell führt ein Crash oder Fehler während einer Schreiboperation (`insert`, `update`, `delete`) in `collection.rs` zwischen dem Commit des LSM-Stores und des HNSW-Index zu einer potenziell dauerhaften Inkonsistenz. Es wird eine transaktionale Klammer in `memfuse-db` benötigt, um sicherzustellen, dass Metadaten (LSM-Store) und Vektoren (HNSW) streng atomar aktualisiert werden ("Alles oder Nichts").

---

## 🛡️ 2. Die Invariante(n) (The "Law")
- **[INV-DB-1] Atomarer Multi-Index Commit**: Ein Commit, der sowohl die Storage-Engine (LSM) als auch den Vector-Index (HNSW) betrifft, darf das System niemals in einem partiell committeten Zustand hinterlassen. Beide Subsysteme müssen den gleichen Transaktionsstatus garantieren.
- **[INV-DB-2] Crash-Recovery Konsistenz**: Nach einem Neustart muss der HNSW-Index exakt den Zustand des LSM-Stores widerspiegeln. Partiell committete Transaktionen im LSM (ohne HNSW-Commit vor dem Crash) müssen entweder im LSM verworfen (Rollback) oder vollständig angewendet werden.
- **[INV-DB-3] Strict Error Visibility in Rollbacks**: Die Verwendung von `let _ = ...` zur Unterdrückung von `Result::Err` in Kompensierungs- und Rollback-Pfaden ist absolut verboten. Fehler während des automatisierten Rollbacks KÖNNEN einen Split-Brain-Status auslösen und MÜSSEN zwingend per `tracing::error!` protokolliert bzw. via `?` propagiert werden, um "Silent Failures" der Datenbank zu verhindern.

## 🛑 4. Definiertes Fehlerverhalten (Fail-Cases)
- Wenn `index.commit()` oder `storage.commit()` fehlschlägt, MUSS die Transaktion abgebrochen werden (`Rollback` der in Memory geänderten States) und `Err(MemFuseError::TransactionAborted)` zurückgegeben werden.
- Abgestürzte Prozesse (Crash zwischen Storage- und Index-Commit): Die DB-Startsequenz (`Collection::open()`) muss das Transaktions-Log verifizieren und unvollständige TXNs entweder verwerfen oder den Index nach-synchronisieren.
