# SPEC-20260520-WP-5.1-6.7-Checkpoint-WAL-Security

## 🎯 1. Das Ziel (Context & "Why")
Implementierung von Checkpoint-Pinning in der Compaction (WP-5.1) zur Unterstützung von Time-Travel Debugging und kryptografische Absicherung des Write-Ahead-Logs (WP-6.7) mittels HMAC-basiertem Hash-Chaining.

> [!NOTE]
> **AUDIT 2026-05-23**: HMAC-basiertes Hash-Chaining wurde implementiert und die Integritätssicherung (`IntegrityVerifier`) erfolgreich durch Unit-Tests verifiziert. Die Korruptionserkennung im WAL-Replay ist stabil.

---

## 🛡️ 2. Die Invariante(n) (The "Law")
- **[INV-CHECKPOINT-1]**: Tombstones dürfen bei der Compaction nur gelöscht werden, wenn ihre `seq_no` kleiner als die globale `min_active_seq` (Snapshots + Checkpoints) ist.
- **[INV-WAL-SEC-1]**: Jeder WAL-Eintrag muss kryptografisch an seinen Vorgänger gebunden sein (Hash-Chain), um Manipulationen oder Dateiverstümmelung zu erkennen.
- **[INV-WAL-SEC-2]**: Die Integrität der Kette muss mittels HMAC verifiziert werden.

---

## 📍 3. Speicherort & API-Signatur
- **Crate**: `memfuse-store`
- **Files**:
    - `src/compaction.rs`: Modifikation von `maybe_compact` und `merge_sstables`.
    - `src/wal.rs`: Erweiterung der `WalEntry` Struktur und der Schreib-/Lese-Logik.

```rust
// In wal.rs (vereinfacht):
pub struct WalEntry {
    pub seq_no: u64,
    pub key: Vec<u8>,
    pub value: Vec<u8>,
    pub hmac: [u8; 32], // Neu: HMAC über (Vorgänger-HMAC + Daten)
}
```

---

## 🛑 4. Definiertes Fehlerverhalten (Fail-Cases)
- Bei Compaction: Wenn die Registry fehlerhafte Daten liefert -> Fehler propagieren.
- Bei WAL-Replay: Wenn ein HMAC nicht übereinstimmt -> `Err(MemFuseError::Corruption)`.

---

## ✅ 5. Der TDD Checkpoint (Red-Phase Vorgabe)
- **Test 1 (`test_tombstone_gc_respects_snapshots`)**: Registriere einen Snapshot/Checkpoint mit `seq_no = 100`. Erzeuge SSTable mit Tombstone `seq_no = 105`. Compaction darf diesen Tombstone NICHT löschen.
- **Test 2 (`verify_chain`)**: Schreibe zwei WAL-Einträge. Modifiziere den ersten Eintrag manuell auf Disk. Das Replay des zweiten Eintrags muss fehlschlagen.
