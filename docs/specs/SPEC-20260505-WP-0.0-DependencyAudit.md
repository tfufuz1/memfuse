## Ziel

Vor jeder Feature-Entwicklung muss die Codebasis frei von:
1. Ungenutzten/unsicheren externen Dependencies
2. `.unwrap()` in Produktionscode (Hot-Paths)
3. `unsafe`-Blöcken außerhalb von `distance.rs`
4. Blockierenden std::fs Calls in async Kontexten

Erst dann ist die Basis für automatisierte Entwicklung stabil.

### AC-4: Async-safe I/O
```bash
# Kein blockierendes std::fs in async Fn außerhalb von Tests:

  | grep -v "/tests/" | grep -v "mod tests"
```

